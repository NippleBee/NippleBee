# About Me

I'm a full-stack developer focused on frontend and native iOS development. I build web applications with React and iOS applications with Swift and SwiftUI, translating real-world requirements into working products.

My work centers on responsive interfaces, API integration, and well-structured application code. I value reusable components, clear separation of responsibilities, and practical architecture that supports a project's growth.

## Web Development

I develop React applications with reusable UI components, state management, and dynamic, API-driven interfaces. My experience includes product catalogs, filtering, search, pagination, and navigation with nested and dynamic routes.

I work with JavaScript, TypeScript, React Router, and REST APIs, using CSS, SCSS, and CSS Modules to build responsive layouts. I also have experience with basic PHP backend development and MySQL integration, including API endpoints, authentication, and session management.

## iOS Development

I build native iOS applications with SwiftUI, separating views, data models, networking, and application logic through an MVVM-style architecture.

My experience includes type-safe navigation with NavigationStack, asynchronous networking with Swift Concurrency, actor isolation, and modeling complex API responses with Codable. I also work with WebView-based authentication, remote images and video, content sharing, and UIKit interoperability.
